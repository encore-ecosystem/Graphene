# Security Policy

## Supported versions

Graphene is pre-release software. Security fixes are applied to the latest
revision of `main`; older revisions are not maintained.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** form in the Security tab of this repository.

Include the affected revision, impact, reproduction steps, and any proposed
mitigation. Please allow maintainers a reasonable period to investigate before
public disclosure.
